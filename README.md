# Willis Brown - Technology Investment & Development Company

Professional website for Willis Brown, LLC - a Delaware-incorporated technology company specializing in SaaS development and digital innovation.

## About Willis Brown

Willis Brown is a technology investment and development company that builds, acquires, and scales innovative SaaS solutions. Founded as a Delaware corporation through Stripe Atlas, we provide entrepreneurs and growing companies with the expertise, resources, and strategic guidance needed to transform ideas into market-leading products.

## Website Features

- **Professional Landing Page**: Showcases company positioning and approach
- **About Page**: Comprehensive company information and corporate structure
- **Contact System**: Professional contact forms and inquiry management  
- **Legal Compliance**: Privacy Policy and Terms of Service pages
- **Trust Indicators**: Delaware incorporation and Stripe Atlas partnership
- **Responsive Design**: Mobile-first approach with modern UI components

## Technology Stack

- **Framework**: Next.js 15.2.4 with React 19
- **Styling**: Tailwind CSS with shadcn/ui components
- **Typography**: Geist Sans & Mono fonts
- **Icons**: Lucide React
- **Language**: TypeScript
- **Deployment**: Vercel (ready for deployment)

This project follows professional development standards outlined in `/docs/WILLIS_BROWN_STANDARDS.md`. Key guidelines include:


## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
